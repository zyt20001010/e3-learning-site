## 直接使用

- 首页提供 P0 核心技术点、知识点搜索、尚未自评通过的内容和个人复习入口。可以按科研问题或共同数学机制查找。
- 68 个独立知识点已经写成快速层与关键推导。每点有自己的 ID、URL、内容状态、收藏、笔记、复习标记与分层自评。
- 快速认知约 3–5 分钟，包含用途、对象、输入输出、逐步手算、核心公式、区别和失败条件。技术掌握约 10–20 分钟，展开关键推导、原课的精确片段和适用实验。按需深入提供相关完整课例代码和文献；严格理论目前仍标为未完成。
- 三种深度读取同一个节点。直接打开新知识点默认为快速层，不需要完成先修课程；局部基础可以在本页展开，并跳到相应独立条目。
- 中英文名称与同义词用于检索；相关词单独标注，不用来合并不同概念。比如平移等变与平移不变、数据 score 与参数 score、MCTS 回传与神经网络反向传播保持区别。
- 原始 910 条覆盖要求均有对应索引。索引条目仍可能是待细化主题；收录名称、翻译名称或列出来源不等于写完教学。完整数字见 `content/knowledge-verification.json`。
- 12 组共同数学机制、9 类科研问题可以连接已有知识点。分组明确说明关系是共享运算、条件联系还是严格恒等式，不将同类方法宣称为等价。

## 学习记录与备份

知识点记录使用 `atom-<id>`；原 Research 课程保持原 ID。两者同存于浏览器 `localStorage` 的 `e3-research-progress-v1`，收藏、笔记与各层自评独立。旧课程完成不会自动变成知识点掌握，访问页面也不会自动完成学习。

“我的复习”中的备份包含新知识点和原 Research 课程记录。导入先校验格式，默认按更新时间合并，并在 `e3-research-before-import-v1` 保存导入前原文。格式损坏时停止自动覆盖。原 E3 的 `yanting-execution-e3-v1` 与教材 IndexedDB 不被读取或修改，仍应在原站备份。备份可能含个人笔记，不要提交到公开仓库。

## 维护与验证

网站无需 npm、R 或 Python 即可使用；KaTeX 与字体为本地资源。需经 HTTP 打开，直接双击 HTML 不支持 ES modules 与 JSON 加载。

在仓库根目录启动预览：

```sh
python3 -m http.server 4183 --bind 127.0.0.1
```

打开 `http://127.0.0.1:4183/research/`。在 `research/` 检查：

```sh
npm ci --ignore-scripts
npm run typecheck
npm run build
npm test
node --check js/app.js
node --check js/knowledge.js
node --check js/knowledge-model.js
```

依赖已安装且未变化时不必重复安装。只有修改原课代码时才重新运行 `npm run verify:examples`；其执行需要 R 与 Python，并核对代码哈希。

43 项自动化检查涵盖原数学与存储功能、新知识点内容/来源/公式、完整覆盖映射、中英文与别名搜索、概念区分、旧新记录备份、应用初始化与真实事件处理函数。应用联检使用小型 DOM/存储替身；它不替代真实浏览器的视觉与操作检查。本次浏览器连接持续超时，视觉验收尚未完成；本地 HTTP 服务已正常响应。

三个作者组对全部 68 个知识点的合成算例进行了独立数值复算。123 条节点公式通过严格 KaTeX 解析；这不代表完整理论证明，也不代表复现了原论文的大型训练或真实生物实验。

## 内容的唯一来源

- `content/knowledge.json`：独立节点正文、别名、相关检索词、状态、原覆盖映射、课程映射和分组关系。A/B/C 三层不各自复制一份正文。
- `sourceRefs`：指向 `content/lessons/*.json` 的精确段落、公式和表格行，索引从 0 开始；空数组表示不提取，不能解释为整段全选。
- `codeLessons`：引用包含本操作的完整原课脚本；页面明确其范围，不冒称每个点都有独立代码。
- `content/catalog.json` 与 `content/lessons/*.json`：保持原课程正文、目录与先修关系。
- `content/knowledge-verification.json`：本次独立知识点与原资源保护的核验范围。
- `js/knowledge-model.js`：纯检索、完成状态与片段选择；`js/knowledge.js`：阅读页面；`js/app.js`：路由、事件与旧页面；`js/progress.js`：既有存储格式。

新知识点优先回答一个明确技术问题，再给出可复算例子、推导、假设与边界。内容未写成时保持状态为 false。来源需与当前知识点实际相关。仅有标题、关键词或代码链接不能标为完成。不要为配合新版结果随意修改 `tests/fixtures/` 中的保留基准。
