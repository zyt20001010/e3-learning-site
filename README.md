# Yanting 学习路线 E3

直接学习：[打开学习网页](https://zyt20001010.github.io/e3-learning-site/)。

无需登录，包含完整学习路线、知识图谱、章节阅读和练习任务。

勾选、笔记和学习进度自动保存在当前浏览器。关闭后从同一浏览器、同一网址打开可继续。记录不会上传到 GitHub；更换设备、浏览器或清理浏览器数据前，请在网页的“进度备份与恢复”导出备份，并在新环境导入。

可下载教材和课件已接入当前教材卡片，也可从网页的“教材与课件下载”统一查找。整本 PDF、章节 PDF 和课程 ZIP 分别标明；部分 PDF 支持在当前页阅读。

目前77项教材与课程资源提供文件入口，共413份不同文件。395份PDF可在网页内按需阅读；大型PDF、课程资料包和其他格式可直接下载。原课程目录中的579个本地文件入口已连接到仓库副本，不需要逐一导入。原文件的版本和课程材料缺口说明保持原样；个人作业与报告保留本地。

文件存储于本仓库的[文件库分支](https://github.com/zyt20001010/e3-learning-site/tree/codex/learning-assets/files)及[大文件下载区](https://github.com/zyt20001010/e3-learning-site/releases/tag/learning-materials-2026-11-03)。网页默认分支只保留页面与目录，避免将整套资料塞入网页部署目录。打开网页不会预下载教材，点击阅读时才读取相应文件。

网站仓库内已有的教材文件会直接供网页读取。How to Prove It 第三版已接到 `materials/how-to-prove-it-3rd-2019.pdf`；在 S001、S002 或 S107 点击“直接阅读教材”即可打开同一份仓库文件，无需本地导入或登录。也可从教材下载区保存 PDF，或查看对应的仓库文件。

未接入仓库的个人教材仍可在教材卡片中“导入本地 PDF”。选择后保存在当前浏览器，随后可在网页内阅读，不上传。相同教材对应的学习步骤共用该文件。

个人教材与学习进度分别保存。教材文件不包含在进度导出中；换设备、清理网站数据或在临时浏览模式中使用时，需要重新选择。浏览器无法保存时，页面会说明仅本次可阅读。

本仓库收录整理后的网页、公开资源链接、课程目录、按许可收录的教材及用户指定接入的现有文件。用户提供的文件与开放许可资源分别标注，不将用户文件标为开放授权。其他作者仅供个人阅读的公开稿连接作者原文件。文件保持原样，来源、署名与许可见 [材料说明](materials/README.md)；大文件的独立下载位于 [教材下载区](https://github.com/zyt20001010/e3-learning-site/releases/tag/textbooks-2026-11-03)。

本仓库不包含私有课件文件或个人学习记录。
