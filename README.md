# Yanting 学习路线 E3

直接学习：[打开学习网页](https://zyt20001010.github.io/e3-learning-site/)。

无需登录，包含完整学习路线、知识图谱、章节阅读和练习任务。

勾选、笔记和学习进度自动保存在当前浏览器。关闭后从同一浏览器、同一网址打开可继续。记录不会上传到 GitHub；更换设备、浏览器或清理浏览器数据前，请在网页的“进度备份与恢复”导出备份，并在新环境导入。

可下载教材和课件已接入当前教材卡片，也可从网页的“教材与课件下载”统一查找。整本 PDF、章节 PDF 和课程 ZIP 分别标明；部分 PDF 支持在当前页阅读。

本仓库收录整理后的网页、公开资源链接、课程目录及许可允许转载的教材副本。作者仅供个人阅读的版本连接作者原文件。教材副本保持原样，来源与许可见 [材料说明](materials/README.md)；大文件的独立下载位于 [教材下载区](https://github.com/zyt20001010/e3-learning-site/releases/tag/textbooks-2026-11-03)。

本仓库不包含私有课件文件或个人学习记录。
